# Code Review Skill

代码审查时，请遵循以下步骤:

## Review checklist

1. **正确性**：代码是否实现了预期功能？ 
2. **边界情况**：是否处理了错误情况？ 
3. **风格**：是否遵循项目规范？ 
4. **性能**：是否存在明显的效率低下问题？


## How to provide feedback

- 具体说明需要改变什么。
- 解释原因，而不仅仅是说明需要改变什么。
- 尽可能提出替代方案。
