# 技术栈

## 后端
- **编程语言**: Java 8
- **框架**: Spring Boot 2.7, Netty 4.1, MyBatis
- **数据库**: MySQL
- **缓存**: Redis
- **构建工具**: Maven
- **其他**: Lombok

## 前端
- **编程语言**: Vanilla JavaScript
- **标记语言**: HTML5
- **样式**: CSS3

## 整体架构
该项目采用前后端分离的架构，后端基于 Spring Boot 和 Netty 构建高性能实时通信服务，并通过 Redis 实现高可用调度。前端使用原生 JavaScript、HTML5 和 CSS3 构建现代化用户界面。
